# Release Notes: Charites v1.0.0 (Initial Public Release)

> **Release Date:** 2026-09-05
> **Tag:** `v1.0.0`
> **Git Commit:** `TBD`

Selamat datang di rilis perdana **Charites v1.0.0** - mesin static analysis mandiri performa tinggi berbasis Go 1.26 untuk memvalidasi kepatuhan tema Tailwind CSS v4, aturan aksesibilitas (A11y), Core Web Vitals, dan praktik frontend terbaik pada proyek Astro dan React/TSX.

---

##  Sorotan Fitur Utama (Highlights)

1. **Native Go 1.26 Architecture:**
   - Single static binary mandiri (`CGO_ENABLED=0`) tanpa dependensi Node.js atau npm di runtime.
   - Pemanfaatan iterator modern Go 1.26 (`iter.Seq`) untuk traversal pohon AST/IR tanpa alokasi memori berlebih (*zero-alloc traversal*).
2. **Unified Frontend IR (Intermediate Representation):**
   - Menormalisasi elemen markup dari template `.astro` dan JSX `.tsx` ke dalam satu struktur data `ir.Node`.
3. **Reference Rule: `theme.hardcode-opacity-color`:**
   - Audit otomatis terhadap utility class dengan slash opacity (misal: `bg-primary/10`, `text-destructive/20`) yang mewajibkan token semantik dari `global.css` (`bg-primary-light`, `text-destructive-light`).
4. **Dual Output Mode:**
   - Format terminal berwarna ANSI (`--format=inline`).
   - Format data bersih JSON (`--format=json`) untuk integrasi pipa CI/CD dan `jq`.
5. **Model Context Protocol (MCP) Server:**
   - Menjalankan server JSON-RPC 2.0 via Stdio (`charites mcp`) untuk interaksi langsung dengan AI coding agents (Antigravity, Claude, Cursor).
