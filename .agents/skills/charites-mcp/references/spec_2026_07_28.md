# Model Context Protocol Specification Notes (Revision 2026-07-28)
**Status:** Canonical Reference for Charites (`github.com/will2469/charites`)
**Mode:** Pure Stateless Request/Response (No Dual-Tracks, No Stateful Handshake)

---

## 1. Definisi Protokol Stateless

Model Context Protocol (MCP) revisi 2026-07-28 mendefinisikan komunikasi antara AI agent/IDE dan tools server:

1. **Transport:** Standard input/output stream (`stdio`) dengan framing JSON-RPC 2.0 per-line (delimited by `\n`).
2. **Karakteristik Stateless:**
   - Server tidak memerlukan inisialisasi bertahap (`initialize` -> `notifications/initialized`).
   - Setiap payload request membawa metadata context `_meta`:
     ```json
     {
       "jsonrpc": "2.0",
       "id": "1",
       "method": "tools/call",
       "params": {
         "name": "charites_scan",
         "arguments": {
           "path": "./src"
         },
         "_meta": {
           "protocolVersion": "2026-07-28",
           "client": {
             "name": "antigravity-ide",
             "version": "2.0.0"
           }
         }
       }
     }
     ```

---

## 2. Model Eksekusi Tools Charites

Server Charites MCP mengekspos 3 tool inti:

### `charites_scan`
- Menjalankan pemindaian AST secara mandiri pada file/direktori.
- Hasil berupa daftar diagnostik pelanggaran desain/aksesibilitas/performa.

### `charites_explain_rule`
- Mengembalikan dokumentasi 8-Pillars dari database aturan atau berkas `wiki/*.md`.

### `charites_list_rules`
- Mengembalikan daftar seluruh aturan aktif dalam format array JSON.

## 3. Format Respons JSON-RPC 2.0

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "result": {
    "content": [
      {
        "type": "text",
        "text": "[{\"rule_id\":\"theme.hardcode-color\",\"severity\":\"HIGH\",\"message\":\"Avoid hardcoded hex color\",\"file\":\"src/Card.astro\",\"line\":12,\"column\":5}]"
      }
    ]
  }
}
```
